# 小鲸鱼的规矩（astrbot_plugin_dafeiyu_rules）

给「大肥鱼/小鲸鱼」加一层**可随手开关的场合规矩**：不动人格卡，也不用重启，
一行一条写在插件配置里，请求前追加到系统提示末尾。

## 它能干什么

- **按场合生效**：同一条规矩可以只对群聊说（`group`）、只对私聊说（`private`），或者都生效（`all`）。
- **一条一行、随便开关**：删掉那行就不再生效；前面加 `#` 是注释，留着但不起作用。
- **有上限**：所有规矩加起来超过 `max_chars`（默认 600 字）就截断，不会把上下文撑爆。
- **改完立刻生效**：插件每轮会重新读配置，改完直接聊就行。

## 装在哪

把整个目录放进 AstrBot 的 `data/plugins/` 下，然后在后台「插件」里重载；
或者在本机跑：

```powershell
python -X utf8 reload.py astrbot_plugin_dafeiyu_rules
```

## 配置

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | 总开关：关掉就一条都不注入 |
| `rules` | text | 空 | 规矩列表，一行一条 |
| `header` | string | `【此刻的规矩】` | 注入那段话的标题 |
| `max_chars` | int | `600` | 注入总字数上限 |
| `inject_channel` | bool | `true` | 每轮附一行「你现在在哪」：QQ / 微信 / 桌面桌宠 / 网页，另有群聊还是私聊 |

`inject_channel` 打开后，系统提示末尾会多出这样一行（私聊不写会话 id，群聊只写群号）：

```
【你现在在哪】主人这条消息是从「桌面桌宠（桌面上那个 Live2D 的她）」的私聊发来的。渠道别答错：主人问起你从哪跟他说话，就照这个说；他说自己在手机/电脑上，那是设备，不是渠道。
```

同一渠道同一场合只记一条日志（`[rules] 渠道提示已注入：微信/私聊（85 字）`），日志里不落会话 id。

`rules` 的写法：

```
all | 说话别太整齐，允许有错别字
group | 群里不要主动聊主人的私事
private | 主人说累了就不要再追问他今天干了什么
# 这行是注释，不会注入
```

范围的写法：`all`／`both`／`全部`，`group`／`群`／`群聊`，`private`／`私`／`私聊`。
时段规矩：在范围前面加 `@开始-结束`（24 小时制），只在这个钟点内注入——

```
@22:00-06:00       | 夜里别催他干活
@22:00-06:00 私聊  | 深夜不主动提学习
```

开始时间大于结束时间就是跨天（22:00-06:00）；两边写同一个时间＝全天；时段写歪了整行会被丢掉，并在`/规矩`里报出来，不会变成全天生效。


## 命令

`/规矩` —— 只给管理员看：列出**当前这个场合**生效的规矩，以及一共存了几条。

## 设计取舍

- **为什么不塞进人格卡**：人格卡是「她是谁」，改动要走审核、也容易越堆越长；
  这类「这几天注意点」的短期约束更适合独立、可开关的一层。
- **为什么按场合而不按群号**：现在只有一个群，按 `group`/`private` 两档就够；
  真需要按群细分，再加一层白名单即可。
- **为什么注入到 `system_prompt` 末尾**：末尾离模型最近，权重大、也不打乱前面的人格与记忆注入。

## 已知限制

- 只管「追加约束」，不能删改人格卡或记忆里的内容。
- 规矩越多占的 token 越多，别写成长篇。
- 只对 AstrBot 主链路生效；插件自己内部另发的请求（比如看图转述）不一定经过这里。
- 渠道提示认不出平台时，会用平台自己报的显示名兜底，可能不是人话（比如 `qq_official`）。
